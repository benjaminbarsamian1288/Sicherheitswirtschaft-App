So geht's

  1. Oben auf App herunterladen tippen. Fragt der Browser „Datei behalten?" oder warnt vor der Datei – Trotzdem herunterladen wählen.
  2. Die Meldung „Download abgeschlossen" antippen – oder die Datei im Ordner Download öffnen.
  3. Android fragt nach der Erlaubnis für diese Quelle: Einstellungen → Zulassen, dann zurück.
  4. Auf Installieren tippen. Kommt eine Play-Protect-Warnung: „Weitere Details" → Trotzdem installieren.
Die Warnungen kommen, weil die App nicht aus dem Play Store stammt – das ist bei eigenen Apps normal. Eine neue Version installiert sich später einfach über die alte, die Einträge bleiben erhalten.
